# InternGrowth Project - PowerPoint Presentation Prompt

## Presentation Overview
Create a minimal, professional PowerPoint presentation for **InternGrowth** - an AI-powered internship management platform that connects students with startups. Use a modern gradient color scheme (indigo, purple, pink) matching the platform's branding.

## Design Guidelines

### **Color Scheme:**
- Primary: Indigo (#6366f1)
- Secondary: Purple (#8b5cf6)
- Accent: Pink (#ec4899)
- Background: White with gradient overlays
- Text: Dark gray (#1f2937)

### **Typography:**
- Headings: Poppins (Bold)
- Body: Inter (Regular)
- Code: Fira Code (Monospace)

### **Visual Elements:**
- Use gradient backgrounds
- Include icons for all features
- Add screenshots of actual platform
- Use flowcharts for processes
- Include code snippets where relevant
- Add animations (subtle)

### **Layout:**
- Consistent header/footer
- Slide numbers
- Logo on every slide
- White space for readability
- Maximum 6 bullet points per slide

---

## Presentation Tips

1. **Keep it visual** - Use screenshots and diagrams, minimal text
2. **Demo live** if possible - Show the actual platform
3. **Highlight AI** - This is your key differentiator
4. **Tell a story** - Problem → Solution → Impact
5. **Practice timing** - Aim for 8-10 minutes total
6. **Prepare for Q&A** - Know your tech stack and features well
