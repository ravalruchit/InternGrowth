## 💬 2. Messaging System

### Features
- ✅ Real-time messaging between students and startups
- ✅ Conversation threads
- ✅ Message history
- ✅ Read/unread status
- ✅ Task-specific conversations
- ✅ Beautiful chat interface

### How to Use
1. **Start a Conversation:**
   - From task page, click "💬 Message Startup" (students)
   - Or go to Messages and select a conversation

2. **Send Messages:**
   - Type your message
   - Click "Send"
   - Messages appear in real-time

3. **View Conversations:**
   - Go to "Messages" in navigation
   - See all your conversations
   - Click to open and chat

### UI Features
- ✅ Bubble-style messages
- ✅ Different colors for sender/receiver
- ✅ Timestamps
- ✅ Scrollable message history
- ✅ Quick message input
- ✅ Conversation list with latest message preview

- `MessageController` - Handles messaging logic

### New Routes
- `/messages` - Message inbox
- `/messages/{id}` - Conversation view
- `/messages/start/{studentId}/{startupId}/{taskId?}` - Start conversation

### Database Tables
